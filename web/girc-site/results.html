The mechanism is close to break-even, and the report says so.

With three transform types over a skewed distribution, the explicit signalling is already cheap for a context-adaptive coder to code. The inference removes that overhead and pays for it in distortion. The margin sweep below is the whole trade.

Method

Every number below comes from the same repository, with the same sequences and the same quantization parameter sweep. GIRC runs in both signalling modes over a four-point QP sweep, and the Bjontegaard delta rate is computed by cubic polynomial interpolation over the overlapping PSNR range, as the JVET common test conditions define it. The two GIRC modes differ in exactly one thing: how the transform type reaches the decoder.

The anchors are the real encoders: x265 for HEVC, SVT-AV1 for AV1 and VVenC 1.14.0 for VVC, each coding the same first frame of the same file and measured by the same PSNR code.

The margin sweep

How predictable is the transform?

The predictor's accuracy is the mechanism's ceiling, so the training pipeline measures it two ways: the shipped logistic regression, and a gradient-boosted tree fitted over the same features as an upper bound on what any model over them can achieve.

Measure Accuracy Reading
Majority class (always DCT-II) 55.53% The baseline any predictor must beat
Gradient-boosted ceiling 56.44% What these features can support
Shipped model 47.35% Trained without class balancing

Per class, the shipped model's held-out accuracy is 52.65% for DCT-II, 57.03% for DCT-VIII and 30.38% for DST-VII.

The honest reading. The ceiling is barely above the majority class. The transform choice is driven by the block's own residual, which the decoder has not seen; the geometry of the neighbourhood constrains it only weakly. That is why the mechanism is close to break-even rather than a clear win, and it is the main thing a codec team would want to challenge.

The consequence is a design limit worth stating plainly: with three transform types over a skewed distribution, the explicit signalling is already nearly free for a context-adaptive coder to code. The mechanism removes an overhead that is smaller than the distortion it costs to remove it.

What would change the answer

More transform types

The overhead the mechanism removes scales with how many choices there are to signal. Three types over a skewed distribution is close to the least favourable case.

A wider causal window

The features read a 16-sample window. A larger one, or a learned representation of the neighbourhood, would raise the predictability ceiling.

Inter prediction

The residual of a predicted block carries the motion vector's structure, which is far more directional than an intra residual and far more predictable from the causal neighbourhood.

Signalling at a coarser grain

Signalling the transform once per region rather than once per block would make the prediction problem much easier and the overhead much larger.
