MEASURED ON XIPH.ORG CIF · 12 SEQUENCES · QP 22–37

The mechanism saves 0.226% of the bitrate.

Twelve CIF sequences, four QP points each, and the inferred mode comes out 0.226% smaller than the explicit mode, and smaller on nine sequences of the twelve. The margin sweep below is the whole trade: the rate the encoder gives up in distortion, against the rate it saves in signalling.

Method

Every number below comes from the same repository, with the same sequences and the same quantization parameter sweep. GIRC runs in both signalling modes over a four-point QP sweep, and the Bjontegaard delta rate is computed by cubic polynomial interpolation over the overlapping PSNR range, as the JVET common test conditions define it. The two GIRC modes differ in exactly one thing: how the transform mode reaches the decoder.

The transform mode is VVC's, not an invention of this repository's: the plain DCT-II, or one of the four per-axis combinations of DCT-VIII and DST-VII that ITU-T H.266 defines as multiple transform selection. The explicit mode codes the mode the way the standard's mts_idx syntax does, which is what the decoder of a real codec would have to read.

The anchors are the real encoders: x265 for HEVC, SVT-AV1 for AV1 and VVenC 1.14.0 for VVC, each coding the same first frame of the same file and measured by the same PSNR code.

How predictable is the transform?

The predictor's accuracy is the mechanism's ceiling, so the training pipeline measures it two ways: the shipped logistic regression, and a gradient-boosted tree fitted over the same features as an upper bound on what any model over them can achieve.

Measure Accuracy Reading
Majority class (always DCT-II) 44.31% The baseline any predictor must beat, over the five modes
Gradient-boosted ceiling, joint mode 44.98% What these features support for the mode as a whole
Gradient-boosted ceiling, one axis 51.75% What they support for a single axis
Shipped model, composed from the two axes 43.07% Per axis: 51.1% horizontal, 51.0% vertical

76,032 blocks, collected from the encoder's own rate-distortion search over twelve sequences at four QP points, so the labels are the encoder's real choices and the features are what the decoder will actually see.

The honest reading. The joint mode is barely predictable: the ceiling of 44.98% is barely above the 44.31% majority class. The transform choice is driven by the block's own residual, which the decoder has not seen, and the geometry of the neighbourhood constrains it only weakly.

Splitting the mode into its two axes is what makes the mechanism work. Each axis on its own reaches 51.75%, a clear margin over the majority class, because the geometry of a neighbourhood says more about the transform on one axis than about the mode as a whole. The shipped predictor therefore models the two axes separately and composes them.

Even so, the saving is 0.226%, not a headline number. The explicit signalling is already cheap for a context-adaptive coder to code, and the mechanism removes an overhead that is close to the distortion it costs to remove it. The margin sweep is the honest account of where that balance sits.

What would change the answer

Inter prediction

The residual of a predicted block carries the motion vector's structure, which is far more directional than an intra residual and far more predictable from the causal neighbourhood.

A wider causal window

The features read a 16-sample window. A larger one, or a learned representation of the neighbourhood, would raise the predictability ceiling.

Signalling at a coarser grain

Signalling the transform once per region rather than once per block would make the prediction problem much easier and the overhead much larger.
