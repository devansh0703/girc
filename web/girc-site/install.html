Install · build it yourself

Three commands, and the codec is on your machine.

Everything is in one repository and every command below is the one the documentation and the CI both use. There is no package to install and no hosted-only feature: the code the service runs is the code here.

The codec

Build and test

git clone https://github.com/devansh0703/girc
cd girc
cargo build --release --workspace
cargo test --workspace

The test suite checks the integer transforms against Fraunhofer HHI's VVenC bit for bit, across all twelve transform and size combinations, and checks the chroma quantization parameter mapping against the same reference implementation for every quantization parameter. It needs the reference implementation: 

git clone --depth 1 --branch v1.14.0 \
    https://github.com/fraunhoferhhi/vvenc.git data/tools/vvenc-src
cmake -S data/tools/vvenc-src -B data/tools/vvenc-src/build \
    -DCMAKE_BUILD_TYPE=Release
cmake --build data/tools/vvenc-src/build --config Release -j "$(nproc)"
./tools/generate_transform_oracle.sh
./tools/generate_chroma_qp_oracle.sh
cargo test -p girc-core transform
cargo test -p girc-core chroma_qp

The reference encoders' oracles are generated from VVenC's own kernels rather than from the standard's text, so the check is against the implementation a codec team would actually build against.

Encode and decode

The command line

./target/release/girc-cli encode input.y4m --output out.girc --qp 27
./target/release/girc-cli decode out.girc --output out.y4m
./target/release/girc-cli inspect out.girc

The --inferred flag selects the signalling mode. Without it the encoder writes the explicit mode, which is the clean rate-distortion optimum the inferred mode is measured against.

The benchmark

Measure it on your own content

source tools/benchmark_env.sh

./target/release/girc-bench \
    --sequence data/seq/foreman_cif.y4m \
    --qps 22,27,32,37 \
    --model models/girc-predictor.json \
    --margin 50 \
    --anchors x265,svt-av1,vvenc \
    --margin-sweep 0,2,5,10,20,50,100,500 \
    --report bench-out/report.json

The report records the tool versions it ran against, so a number can be traced to the state that produced it. Point --sequence at your own material and the comparison runs on your content rather than only on the twelve CIF sequences the published figures come from.

The training pipeline

Fit your own predictor

pip install -r python/girc-train/requirements.txt
export PYTHONPATH=python/girc-train

python3 -m girc_train collect --sequences data/seq/*.y4m \
    --output bench-out/training.jsonl
python3 -m girc_train fit --input bench-out/training.jsonl \
    --output models/girc-predictor.json

The collection pass runs the encoder itself, so the training set is the encoder's actual behaviour and not a proxy for it, and the features are taken from the reconstructed neighbourhood exactly as the decoder will see them. The fit runs on the GPU when one is present and on the CPU when it is not, and the two agree on the result: the same data gives 50.17% test accuracy on the GPU and 50.18% on the CPU. 

uv pip install --python .venv/bin/python \
    -r python/girc-train/requirements-gpu.txt

The model records which backend produced it, in training.estimator_backend, so a fit is attributable. The predictability ceiling is a gradient-boosted tree, which stays on the CPU because cuML has no histogram gradient boosting.

Run your own figures

Regenerate the site's figures

Every figure on this site is generated from a committed artifact by one script, so you can check that a figure you are looking at is the one your run produces: 

.venv/bin/python tools/generate_figures.py
.venv/bin/python tools/assemble_site.py
.venv/bin/python tools/verify_benchmark_numbers.py \
    research/benchmark/report-v9-joint.json

The third command is the one that matters most: it reads the benchmark report and checks that every figure the documents quote is the one the report holds. It has caught a number changed in one place and not in the others, which is exactly the drift a project whose value is checkable claims cannot afford.
